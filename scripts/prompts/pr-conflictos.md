Resolver conflictos (Cubicle): el PR #{{n}} de {{repo}} ({{head}} → {{base}}, {{url}}) está en conflicto. Resuélvelos SIN tocar mi rama actual ni mi árbol de trabajo: usa un worktree aparte.
Pasos: 1) `git fetch origin {{base}} {{head}}`. 2) `git worktree add .cubicle-pr-{{n}} origin/{{head}}` y trabaja SOLO dentro de esa carpeta. 3) `git merge origin/{{base}}` y resuelve cada conflicto conservando la intención de AMBOS lados (lee el diff del PR y los commits recientes de {{base}} para entender qué quería cada uno); nunca descartes un lado por comodidad. 4) Si el repo tiene typecheck, lint o tests rápidos, córrelos dentro del worktree y arregla lo que rompa la mezcla. 5) Commit: "merge {{base}} into {{head}}: resolve conflicts". 6) Muéstrame un resumen por archivo de cómo resolviste cada conflicto y PREGÚNTAME antes de hacer `git push origin HEAD:{{head}}`. 7) Al terminar (con push o sin él) elimina el worktree con `git worktree remove .cubicle-pr-{{n}}`.
Si un conflicto requiere una decisión de negocio que no puedes inferir, detente en ese punto y pregúntame con las dos opciones explicadas.
